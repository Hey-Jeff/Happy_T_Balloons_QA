QA02 Sprint 72 horas — Paquete D1
==================================
Los archivos dentro de "repo/" son CAMBIOS PARCIALES que reemplazan o crean rutas
idênticas en Hey-Jeff/Happy_T_Balloons_QA. No borres el repositorio.

Para integración automática si tienes Git instalado y autenticado:
  1) git clone https://github.com/Hey-Jeff/Happy_T_Balloons_QA.git
  2) Copia el contenido de la carpeta "repo/" encima de la carpeta clonada,
     preservando las rutas de carpetas y aceptando reemplazar los archivos.
  3) En el repo: git add . && git commit -m "QA02 sprint D1 16 nuevos flujos"
  4) git push origin main

O, usando la interfaz de GitHub: abre la ruta de cada archivo de "repo/",
usa "Edit" en los existentes y "Add file" en los nuevos. No pegues texto
al final de archivos; reemplaza el contenido completo.

Después: Actions > QA02 manual > Run workflow > modo VALIDAR, branch MAIN,
luego modo PUBLICOS, http_auth APAGADO.

No hagas Re-run jobs cuando hayas modificado archivos: usa Run workflow.
Consulta docs/PLAN_72_HORAS.md para el plan de los tres días.
